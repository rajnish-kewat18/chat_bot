Chatbot

🚀 Overview

The Chatbot project is a simple web-based application built using HTML, CSS, and JavaScript. It simulates basic chatbot interactions where users can type queries, and the bot responds with predefined answers. This project demonstrates the use of frontend web technologies and client-side scripting to create an interactive chatbot experience.

🔑 Features

- Interactive chatbot UI with a clean design.

- Accepts user input and responds with predefined messages.

- Scrollable chat window with real-time updates.

- Responsive design for desktop and mobile screens.

- Lightweight and runs entirely in the browser (no backend required).

⚙️ Tech Stack

- Frontend: HTML, CSS, JavaScript

- Logic: Rule-based responses in JavaScript

📂 Workflow

- User enters a query in the chatbot input field.

- JavaScript matches the query with predefined responses.

- The chatbot displays the corresponding reply in the chat window.

- Conversation continues until the user closes the session.

🔮 Future Scope

- Add AI/ML-powered responses (e.g., integration with NLP APIs).

- Store chat history locally.

- Voice-based input and speech responses.
